# PART 2: PROJECT BRIEF

## Project Title
Camera-Based Athlete Testing and Performance Tracking System

## 1. Project Overview

The project involves developing a proprietary computer vision system that uses video footage from a single stationary camera to measure athletic performance.

The system should automatically track an athlete completing a standardized movement course, detect important events such as starting, intermediate and finishing points, and calculate accurate elapsed times.

The long-term objective is to expand this into a commercial athlete performance analysis platform capable of measuring speed, acceleration, movement patterns and other performance metrics.

The system should minimize reliance on traditional electronic timing gates and wireless sensors by using camera-based measurement techniques.

## 2. Problem Statement

Traditional athletic testing systems often depend on electronic timing gates and wireless sensors.

The objective is to develop a camera-based alternative that can automatically measure athlete performance using video footage.

The challenge is to convert video information into accurate and repeatable physical measurements.

This requires reliable athlete detection, tracking, event detection, timestamp extraction, camera calibration and measurement validation.

## 3. Project Objectives

### Initial Objectives — Proof of Concept

Develop a system that can:

1. Process video recorded by a single stationary camera.
2. Detect and track one athlete.
3. Support a predefined course configuration.
4. Identify starting and finishing positions.
5. Automatically detect start and finish events.
6. Calculate elapsed time accurately.
7. Ideally calculate intermediate split times.
8. Validate measurements against a reliable reference timing system.
9. Produce structured performance results.

### Long-Term Objectives

Expand the system to support:

- Speed measurement.
- Acceleration measurement.
- Movement and transition timing.
- Athlete movement trajectories.
- Changes in speed throughout training.
- Performance comparisons over time.
- Affordable camera deployment, including smartphones and tablets.
- Scalable deployment across hundreds of training facilities.

## 4. Functional Requirements

The initial system should support:

The system must be evaluated based on actual measurement performance, not simply whether it can detect and track an athlete.

## 7. System Architecture

The proposed processing workflow is:

1. Camera records the athlete.
2. OpenCV reads and processes the video.
3. YOLO detects the athlete.
4. A tracking algorithm maintains the athlete's identity and position across frames.
5. Event detection identifies start, intermediate and finish crossings.
6. Timestamp extraction determines when each event occurred.
7. Time measurement calculates elapsed and split times.
8. Camera calibration and coordinate mapping support real-world distance and speed measurement where feasible.
9. Results are generated in a structured format such as JSON.
10. An API communicates the results to the company's existing web platform.
